新的博客框架！全量上线！

基于Astro的Mete0r专用主题上线啦！

本站博客正式完成框架迭代，从 Hexo 迁移至 Astro 自建定制主题！搭载流畅动画、多配色模式、智能搜索等实用功能，适配全设备，联动动态友链、说说等特色页面，性能大幅优化，后续将持续完善站点功能与体验。

博客#博客#更新#Astro

01. 引言

首先呢在这里立下一个里程碑，我终于从开源主题的世界里进入到了自己定制化主题的行列

由于主题处于Alpha测试版本，如果大家在使用中发现什么奇奇怪怪的Bug，欢迎在评论区指出，我会立刻修复

02. 关于主题与框架

我目前的这个博客主题顺利从Hexo-Stellar主题过渡到了Astro框架的自建主题，在这里感谢Hexo-Stellar主题对开源社区的大力付出
此主题目前在A测阶段，并未计划在短期内进行开源，待到主题无恶性Bug后，便会酌情准备开源计划

此主题由Mete0r与Codex一同制作，目前适配的功能有：

2.1 设计与界面

  • 基于 Astro 和 Tailwind CSS 构建
  • 使用 Swup 实现流畅的动画和页面过渡
  • 使用 NotoSans 字体的清晰体验
  • 明暗主题/绿色粉色配色模式自由切换
  • 全设备响应式设计，已优化移动端体验

2.2 内容与搜索

  • 基于 Pagefind 的高级搜索功能
  • 增强的 Markdown 功能，支持语法高亮
  • RSS 订阅生成
  • 阅读时间估算
  • 文章分类和标签(样式借鉴自归档 | LiuShen’s Blog - 清羽飞杨)

2.3 特色页面

  • 友链页面 - 基于Hexo-Stellar-Friend的Github友链自动获取项目所拉去的json，动态加载友链页面
  • 说说页面 - 基于对接Ech0系统的说说博客内展示功能
  • 归档页面 - 有序的文章时间线视图
  • 关于页面 - 人物简介/站点简介/隐私政策/版权政策

2.4 技术特性

  • 性能优化，内存占用低至100M以内
  • 评论系统，Artalk 集成，并自动适配主题配色及显示模式

有些承诺的页面并没有及时补全，请大家见谅，交流区会逐步上线

03. 未来规划

  1. 交流区板块（页面内纯评论系统，并随机展示本站内评论）
  2. 评论前端样式改版，更加适配主题
  3. 在我能力范围内，使用更多性能优化工具优化首屏加载时间
